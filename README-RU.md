# FVT Player Sheet — Foundry VTT 14 / Custom System Builder 6.x

Это экспериментальный локальный модуль, созданный из SVG-прототипа FVT. Он **добавляет ещё один вариант листа `character`**; CSB остаётся установленной игровой системой и редактором шаблонов. Макет 1540 × 1025 автоматически уменьшается под ширину окна.

## 1. Установка

1. Сделайте резервную копию мира Foundry.
2. Установите Foundry VTT v14 и игровую систему **Custom System Builder 6.0.2** (или совместимую версию 6.x).
3. Распакуйте архив так, чтобы получилось: `<User Data>/Data/modules/fvt-csb-sheet/module.json`. Внутри этой папки также должны лежать `fvt-csb-sheet.mjs`, `fvt-player-sheet.css`, каталоги `assets` и `templates`.
4. Перезапустите Foundry, откройте мир с системой CSB и включите модуль **FVT — Player Sheet for Custom System Builder** в настройках модулей мира.
5. Создайте/откройте актёра типа `character` с применённым шаблоном CSB. Откройте настройки листа (Configure Sheet / «Настроить лист») и выберите `FVT — Player Sheet (SVG)` как лист **для этого персонажа**. Исходный лист CSB остаётся доступен в том же меню.

Если название FVT не появляется в настройках листа, убедитесь, что включили модуль и актёр имеет тип `character`, а не `_template`.

## 2. Подготовка шаблона CSB (обязательно для надёжного сохранения)

В CSB создайте актёра типа `_template`, добавьте в него нижеперечисленные поля с **точно такими же ключами** (все латинскими буквами и подчёркиваниями). Для каждого персонажа выберите этот шаблон, затем примените/обновите его штатной кнопкой CSB. Отдельная визуальная расстановка полей внутри шаблона не нужна: FVT рисует их поверх SVG независимо от расположения в CSB.

**Текстовые поля (Text Field или подходящий компонент ввода текста):**

- `race`, `subrace`, `birth_city`, `notes`, `bio`.

**Целочисленные поля (Number Field, целые):**

- `age`;
- `special_s`, `special_p`, `special_e`, `special_c`, `special_i`, `special_a`, `special_l` (допустимо от -5 до 20);
- `originium_infection` (сегменты заражения, целое от 0 до 32).

**Числовые поля, допускающие дробные значения:**

- `originium_resistance`;
- `health`, `defense`, `speed`, `initiative`;
- `skill_melee`, `skill_ranged`, `skill_medicine`, `skill_survival`, `skill_technique`, `skill_social`, `skill_arts`.

Используйте именно компоненты **ввода**, если хотите редактировать значения в листе FVT. Если характеристика рассчитывается формулой CSB, определите исходные вводимые данные отдельно и не ожидайте, что ручное значение вычисляемого поля сохранится после пересчёта.

Имя и портрет являются стандартными полями Foundry (`actor.name` и `actor.img`) и не требуют компонентов CSB. Инфекция в FVT хранится как число из **32 сегментов**, а не как процент: для отображения процента применяется формула `число / 32 × 100`.

## 3. Инвентарь

Создайте в CSB один или несколько `_equippableItemTemplate`, а по их образцу — предметы типа `equippableItem`. Кнопка «Добавить» в FVT позволяет взять копию предмета из мирового справочника Items либо создать пустой `equippableItem` и открыть штатный редактор CSB, чтобы применить шаблон.

- Кнопка «Открыть CSB» открывает стандартный лист самого предмета.
- Имя предмета обновляется в Foundry.
- Описание пишется в `item.system.props.description`, **если** такой ключ определён в шаблоне предмета. Иначе для него используется резервное хранилище `flags.fvt-csb-sheet.description`.
- Перенос между «Экипировано» и «Рюкзак» сохраняется как `flags.fvt-csb-sheet.equipped`. Это **визуальная группировка**, она сама по себе не включает/отключает эффекты CSB. Для игровой механики экипировки потребуется дополнительная привязка к правилам твоей системы.
- «Удалить» с подтверждением удаляет встроенный предмет у персонажа, но не мировой образец.

## 4. Черты, биография, права

- Теги черт сохраняются в `actor.flags.fvt-csb-sheet.traitSlots` (4 слота, по 8 тегов). Начните тег с `!`, чтобы он был отрицательным (красным). Это пока отображение черт, не Active Effects.
- Заметки и биография сохраняются в `actor.system.props.notes` и `actor.system.props.bio`. Биография допускает ограниченный набор простого форматирования (полужирный, курсив, подчёркивание, H2, список); изменения сохраняются при потере фокуса.
- Поля редактирует только пользователь с правом обновлять персонажа. При отсутствии прав интерфейс становится только для чтения.
- Никаких игровых бросков, автоматических модификаторов предметов и создания готового `_template` модуль не добавляет: это нужно настроить в CSB в соответствии с твоими правилами.

## 5. Диагностика

Если поле не сохраняется: проверь точное совпадение ключа и тип компонента в CSB, применение шаблона к персонажу, права доступа и сообщения в консоли Foundry (`F12`). Если прежние актёры используют старую версию шаблона, обнови их из исходного листа CSB. Не редактируй `preview.html` ради интеграции — модуль использует `templates/actor-sheet.hbs` и `fvt-csb-sheet.mjs`.

**Статус:** исходники проверены статически на синтаксис и структуру, но этот локальный модуль не запускался в реальном экземпляре Foundry. Перед использованием в основной кампании протестируй его на копии мира.
